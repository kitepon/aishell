# AIShell 0.7.0

この版は操作機能を過剰に削除したため撤回対象です。0.7.1で元の操作機能を復元しました。以下は公開当時の記録です。

AIがmacOSの操作を直接呼び、結果を受け取るための製品に整理しました。

- 公開toolをファイル操作、プログラム実行、他アプリ操作に統一しました。
- 管理UI、停止スイッチ、Keychain認証、所有者認証を削除しました。
- 編集取引、巻き戻し用記録、暗号化store、workspace監視、checkpoint、cache、artifact管理、自動試験選択、専用診断とprofileを削除しました。
- ファイル書込みはハッシュ指定なしで利用できます。ハッシュを指定した場合だけ一致を確認します。
- 指定した引数、標準入力、出力を保持し、黙った数値補正や出力省略を廃止しました。
- 使用日時、操作、対象、成功・失敗を既存のactivity.jsonlへ保存します。
- 配布物を実行ファイルへ変更し、aishell-openと管理アプリを廃止しました。setupはAI登録とMCP実操作を確認します。

旧toolとprofileは廃止されています。呼出元はtools/listで現在の直接操作を取得してください。旧設定・編集記録・Keychain項目は読み込まず、使用ログは引き継ぎます。

更新はnpm install -g @quolu/aishell@latestの後、aishell-setupを実行してください。旧版のウィンドウを終了し、AIセッションのMCPを再接続してください。

検証: Swift 17件、setup 28件、公開commit gate 1件、repository契約8件が成功しました。実際のnpmパッケージを一時環境へ導入し、AI登録、ファイル操作、直接実行、アプリ一覧、使用ログも確認しました。

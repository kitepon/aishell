# AIShell 0.5.0

操作対象フォルダの登録と範囲制限を削除した。インストール後、macOSのアクセス権で操作できるフォルダをそのまま指定できる。

- 管理画面のフォルダ追加・削除・一覧を廃止し、操作の停止・再開と履歴を表示する。
- 絶対パスは指定した場所を、相対パスと省略時はMCP起動ディレクトリを基準にする。Git worktreeの事前登録や自動許可判定も不要になった。
- 旧設定の`allowedRootPath`・`allowedRootPaths`は無視し、次の設定保存時に除去する。停止状態は引き継ぐ。
- `runtime_status`から許可フォルダ一覧を除去した。相対パスの基準は`relativePathBase`で返す。
- Runtime設定schemaを`aishell.runtime_configuration.v3`へ更新した。工場診断schemaは維持し、旧root件数は0で返す。

停止、Trash、SHA競合検出、操作ごとのworkspaceとcursorの束縛は引き続き有効。

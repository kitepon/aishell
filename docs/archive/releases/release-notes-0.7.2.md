# 0.7.2

編集状態の暗号化、ローカル鍵の新規作成、所有者証明とその消費記録、registryのHMACと重複CRC検査を削除した。管理UIの廃止後も各操作に残っていた停止設定の読取りも削除した。新しい編集記録はJSONで保存する。

全29ツールとAIへのMCP設定を維持する。SHAによる編集競合検出、Trash、復旧記録、差分と実行結果のartifact、使用ログ、検索・実行結果の継続取得は引き続き利用できる。

旧暗号化記録は既存のローカル鍵で読める。履歴や鍵の一括削除・変換は行わず、通常の編集で更新する記録からJSONへ切り替える。更新後の記録は暗号化のみ対応の旧版では読めない。

0.7.1が実際に保存した記録を用い、更新後の編集と再起動後の編集を確認した。配布packageの検査では全29ツール、鍵を作らない編集、JSON保存、実行監視の完了を確認する。
